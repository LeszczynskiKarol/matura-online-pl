## Strategia: uzupełnianie luk na rozszerzonym

Na PR luki są **krótsze** (1-3 wyrazy) ale **wymagają pełnej precyzji** — każda literówka = 0 pkt. Klucz CKE jest bardzo szczegółowy.

<div class="krok">
  <div class="krok-label">Krok 1 — analiza otoczenia luki</div>

Zobacz, co stoi przed i po luce w notatce. To wskaże gramatyczną formę odpowiedzi (rzeczownik? forma czasownika? przyimek + rzeczownik?).
</div>

<div class="krok">
  <div class="krok-label">Krok 2 — pierwsze odsłuchanie</div>

Wpisuj odpowiedzi natychmiast, nawet jeśli nie jesteś pewny ortografii.
</div>

<div class="krok">
  <div class="krok-label">Krok 3 — drugie odsłuchanie</div>

Weryfikuj **dokładny zapis** wyrazu — czy `silent` ma `i`, nie `a`? Czy `week` ma `ee`, nie `ea`?
</div>

## Klucz odpowiedzi (z akceptowanymi wariantami CKE)

<div class="odpowiedz">
  <div>

### 3.1. — `in silent mode`
**Klucz**: przed wejściem do biblioteki należy ustawić telefon w trybie cichym.
**Akceptowane**: `put into/in silent mode`, `put on/to silent mode`, `put on silent/mute`, `turned to/into silent mode`, `turned down to mute`, `switched to silent mode`, `set in silent mode`, `muted / silenced`, `in mute/muted mode`, `in quiet mode`. Z dopuszczalnym błędem: `put in/into/to silent/mute`, `put on/in a silence mode`, `on silence mode`, `in silenced mode`, `on silent`, `silent`, `completely quiet`, `with the sound turned off`.
**Odrzucone**: `switched off / turned off / put off` (niezgodne — `off` ≠ silent mode), `left outside the zone / left in the locker`, `(very/really) quiet`, `not too noisy` (niezgodne z tekstem), `in sailent mode / in silent moude` (błąd ortograficzny), `in salient mode / on the silent moat / in silent mote` (zmiana znaczenia), `(into) silent mode / you should switch it to silent mode / turn down/switch to mute` (niespójne z otoczeniem), `in silent mood / in silence / mute / put in silence/silent condition / turned off to mute / in silent moda` (niejasne), `put in sleep mode / set to flight mode / on (a/the) mode` (nieprecyzyjne).

### 3.2. — `(the library) security gate`
**Klucz**: po wyciszeniu telefonu należy przejść przez bramkę bezpieczeństwa.
**Akceptowane**: `(a/the) security gate`, `security gate of the library`, `library's security gate`, `security entrance`, `security checkpoint`, `security`, `security check`, `security section`, `security zone/area`. Z dopuszczalnym błędem: `security gates`.
**Odrzucone**: `common room / reception / secretary gate / security room / the door of the library / the red zone / security line` (niezgodne), `gate / gates / library / building / door / corridor` (nieprecyzyjne), `reception and security gate / library and security gate / corner room in the security gate` (niezgodne uzupełnienie), `safe/safety gate / secure gate / security entry / security stage / security space / security system / call/calling room / calm room / corner room / special room / office room / the library next to reception` (niejasne), `security guards / beyond the security line` (niespójne z otoczeniem).

### 3.3. — `a/the week`
**Klucz**: rezerwacja na tydzień przed wizytą.
**Akceptowane**: `7 days / seven days`, `week / one week`, `week ahead / in advance`.
**Odrzucone**: `weeks` (nieprecyzyjne), `a weak` (zmiana znaczenia — `weak` = słaby), `30 minutes / a week after the first visit / a week early` (niezgodne z tekstem), `application at reception / one/a weeks / one week's / on week / in one week` (niejasne), `one week's notice` (niespójne z otoczeniem luki).

### 3.4. — `pay (for the use of a locker / to use a locker)`
**Klucz**: nie ma konieczności płacenia za korzystanie z szafki.
**Akceptowane**: `pay for it/them`, `pay a/the (locker) fee`, `pay a fee/charge for using lockers`, `pay charges`, `pay (the fee) for using it/them`, `pay for access to the lockers`, `pay (any/some) money`, `pay for a/the lockers`. Z dopuszczalnym błędem: `pay for locker fee`, `pay the cost`.
**Odrzucone**: `pay a ticket / give money / charge (lockers) / follow that rule / charge their online card / file` (niejasne), `pay a lot / leave/carry books / have/book lockers / obey the rules / keep (only) the library books in the lockers / pay for booking lockers / pay for storing / pay additional fee` (niezgodne), `pay online` (niezgodne uzupełnienie), `no charge / be charged/paid` (niespójne z otoczeniem).

  </div>
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — homofony `silent` vs `salient`, `week` vs `weak`</div>

Klucz CKE wprost klasyfikuje jako 0 pkt: `a weak` zamiast `a week` (`weak` = słaby), `in salient mode` zamiast `in silent mode` (`salient` = wystający). Homofony brzmią tak samo, ale są innymi wyrazami.
</div>

### Dla zdających z dysleksją

Akceptowane: `3.1. silense mode / silent moude`, `3.2. seciurity gate / security gatte`, `3.4. pay a fea`.

## Punktacja CKE

- **1 pkt** — poprawna odpowiedź (za każde z 3.1.–3.4.).
- **0 pkt** — odpowiedź niepoprawna albo brak odpowiedzi.
- Maksymalnie **4 pkt**.
