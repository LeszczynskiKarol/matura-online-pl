### 6.5. — `power / electricity`
**Klucz**: awaria dostarczania prądu/oświetlenia.
**Akceptowane**: `lighting`, `light(s)`, `electrical`, `energy`, `kind of power`, `darkness due to electricity`, `lack of light because of power`, `light system`, `delivery of light`, `electricity circuit`, `power supply`, `(power) generator`. Z dopuszczalnym błędem: `electric`. Bez wpływu na znaczenie: `dark because of power`.
**Odrzucone**: `machinery / electronic / power grid` (niezgodne), `system` (nieprecyzyjne), `power cut / blackout / outage / power load(s) / lack of light / went dark / powering / power up / light power` (niespójne z fragmentem po luce), `lightening` (błąd zmieniający znaczenie), `kind of / technical` (nieprecyzyjne), `electricty` (zła ortografia).

### 6.6. — `airplane crash sites`
**Klucz**: miejsca wypadków lotniczych.
**Akceptowane**: `plane accident sites`, `places where airplanes had crashed before`, `sites of plane crashes`, `crashed planes`, `airplane crash cases`, `airplane accidents`, `airplane wrecks/wreckage`, `aircraft crashes`, `crashed aircraft`, `plane collisions`, `airplane crash causes`, `aeroplane accident`. Z dopuszczalnym błędem: `airplane crash/accident`, `planes crash site`, `an airplane crashes`, `of/about/in/at airplane crash sites`, `of/into airplane accidents`.
**Odrzucone**: `spacecraft / spacecraft crashes / coral growth` (niezgodne), `place where planes crashed into sea` (zawiera niezgodny fragment), `discovering airplane crashes / with airplane crash sites` (niejasne), `crash sites / airplane incidents` (nieprecyzyjne), `crash sides / crash sights / plain crashes / airplane crush sites` (błąd zmieniający znaczenie), `the places where planes had different accidents` (przekroczony limit).

### 6.7. — `its age`
**Klucz**: wiek statku kosmicznego / czas wypadku / okres spoczywania na dnie.
**Akceptowane**: `its real/exact/precise age`, `its age accurately`, `how old it is`, `the age of the object`, `how old the spaceship really is`, `her age`, `how old is the ship`, `when the spacecraft crashed`, `the time of the spacecraft's crash`, `the date it fell down`, `the time when it happened`, `the moment of the crash`, `the date of that crash`, `how long it lies/has lain/lay underwater`, `when it crashed on the Earth`, `time when it hit the ocean`. Z dopuszczalnym błędem: `how old is the spacecraft`, `the age of it`, `when did it actually happen`, `a/the century that it crashed`, `time when the spacecraft was crashed`, `how long ago it has fallen`, `how old was the craft`.
**Odrzucone**: `age` (nieprecyzyjne), `how the accident happened / how long ago the ship sinked` (niezgodne), `how long it was underwater after it crashed` (przekroczony limit), `the age of (the) discovery / how many years can spacecraft have / how old the spacecraft's is / pacific coral / how old is / because of covering in coral / the deep that it is / how long it lain/layed / his age / how long are this spacecraft / it's age / the exact time when it collapsed / time of sinking / the ship's years` (niejasne), `how long ago it crushed / how long it lied underwater` (błąd zmieniający znaczenie — `crushed`/`lied`), `the age of the military spacecraft` (uzupełnione niezgodnym), `wiek statku` (zły język).

### 6.8. — `was sent for / was summoned`
**Klucz**: Dr. Johnson został wezwany do zbadania sprawy. Strona bierna wymagana przez `by Barnes` po luce.
**Akceptowane**: `was contacted`, `was ordered to come`, `was invited`, `was hired/employed`, `was chosen (to help)`, `was called`, `got called in`, `was called up`, `was chosen to this case`, `was sought out`, `was picked`. Z dopuszczalnym błędem: `has been called in`, `has been brought` (Present Perfect), `had been sent for` (Past Perfect), `was appreciated`, `was requested / asked for`, `is needed`, `were sent for`, `were brought (in)`, `was being recruited`, `has been called to investigate`, `was involved`, `was called here`, `is called / contacted / chosen` (Present Simple), `was sumoned` (jeden błąd).
**Odrzucone**: `discovered / contacted / was joking / was on the ship / was there / was call / was inviting` (niespójne), `was sent (there/to this investigation) / is/was seen as the only option / was ordered` (niezgodne), `was asked / was informed / got caught / was taken for a spacecraft expert / was wanted to come / was being looked for / was taken / was known / was called on wreck` (niejasne), `was choosen / was broght / has been invitet` (zła ortografia), `was chosen to investigate the problem with the spacecraft` (przekroczony limit).

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `crashed` vs `crushed`</div>

`crashed` = rozbił się (samolot, statek). `crushed` = zgnieciony. Klucz CKE: `how long ago it crushed` = 0 pkt z błędem zmieniającym znaczenie.
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `lay/lain` vs `lied`</div>

`lay/lain` = leżeć (intransitive). `lied` = kłamał (od `lie` = kłamać). Klucz CKE: `how long it lied underwater` = 0 pkt.
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `lighting` vs `lightening`</div>

`lighting` = oświetlenie. `lightening` = rozjaśnianie (czasownik `lighten`). Klucz CKE wprost: `lightening` = 0 pkt z błędem zmieniającym znaczenie.
</div>
