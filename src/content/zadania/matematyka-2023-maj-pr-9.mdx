## Co zrobić?

<div class="kroki-lista">

<div class="krok">

**Rozpoznaj kwadraty pełne pod pierwiastkami.**

$$x^2 + 4x + 4 = (x+2)^2 \implies \sqrt{(x+2)^2} = |x+2|$$

$$x^2 - 6x + 9 = (x-3)^2 \implies \sqrt{(x-3)^2} = |x-3|$$

Nierówność przyjmuje postać:

$$|x+2| + |x-3| < \frac{25}{3}$$

</div>

<div class="krok">

**Rozpatrz 3 przypadki znaków modułów** (krytyczne punkty: $x = -2$ i $x = 3$).

**Przypadek 1: $x < -2$.** Wtedy $|x+2| = -(x+2)$, $|x-3| = 3-x$:

$$-(x+2) + (3-x) = -2x + 1 < \frac{25}{3}$$
$$-2x < \frac{22}{3} \implies x > -\frac{11}{3}$$

Razem z $x < -2$: $-\frac{11}{3} < x < -2$.

</div>

<div class="krok">

**Przypadek 2: $-2 \leq x < 3$.** Wtedy $|x+2| = x+2$, $|x-3| = 3-x$:

$$(x+2) + (3-x) = 5$$

$5 < \frac{25}{3}$? $5 = \frac{15}{3} < \frac{25}{3}$ ✓

**Cały przedział $-2 \leq x < 3$ jest rozwiązaniem.**

</div>

<div class="krok">

**Przypadek 3: $x \geq 3$.** Wtedy $|x+2| = x+2$, $|x-3| = x-3$:

$$(x+2) + (x-3) = 2x - 1 < \frac{25}{3}$$
$$2x < \frac{28}{3} \implies x < \frac{14}{3}$$

Razem z $x \geq 3$: $3 \leq x < \frac{14}{3}$.

</div>

<div class="krok">

**Zbierz wszystkie przedziały:**

$$\left(-\frac{11}{3}, -2\right) \cup [-2, 3) \cup \left[3, \frac{14}{3}\right) = \left(-\frac{11}{3},\ \frac{14}{3}\right)$$

</div>

</div>

## Po co to umieć

**$\sqrt{a^2} = |a|$** — fundament. To dlatego $\sqrt{x^2} \neq x$ dla wszystkich $x$.

**Geometryczna interpretacja**: $|x - a|$ = odległość $x$ od $a$. Wyrażenie $|x+2| + |x-3| = |x - (-2)| + |x - 3|$ = suma odległości $x$ od $-2$ i od $3$.

Dla punktów **pomiędzy** $-2$ a $3$ ta suma jest stale równa $5$ (długość odcinka). Poza nim — rośnie liniowo. To pozwala szybciej rozumować geometrycznie.
