### 3.1. — `teamwork / cooperation / co-operation`
**Klucz**: kluczowa umiejętność rozwijana na obozie — współpraca / praca zespołowa.
**Akceptowane**: `teamwork and cooperation`, `working together / work together`, `working as a team / in teams`, `team working`, `teamwork skills`, `learning in/as/with a team`, `working with others`, `collaboration/collaborating/cooperating`, `working on the team`, `team building`, `team project work`, `group work`, `working in groups`, `students/people to work in groups`, `taking part in group project(s)`. Z dopuszczalnym błędem: `to working in a group`, `to teamwork`, `co operation`, `team work` (rozdzielnie).
**Odrzucone**: `corporation` (zmiana znaczenia!), `tim work` (zła ortografia — wyraz wysokiej frekwencji), `working / learning / essential skill(s) / talking to each other / sharing ideas with each other / be in groups` (nieprecyzyjne), `working in pairs / social activities / help of experts / hard work / to form project groups / to take part in workshop / to focus` (niezgodne z tekstem), `practice / future career / university / education / close to each other / team / group projects / works in a team / team work project` (niejasne).

### 3.2. — `(traditional) Scottish dances / Scottish dancing`
**Klucz**: uczestnicy uczą się tradycyjnych tańców szkockich.
**Akceptowane**: `Scottish way of dancing`, `dances from/of Scotland`, `to dance Scottish dances`, `dances traditional in Scotland`, `Scots dances`, `traditional Scottish dance` (l. poj.). Z dopuszczalnym błędem: `traditional scottish dancing` (mała litera), `typical Scotish dances` (brak podwojenia `t`).
**Odrzucone**: `dances in Scotland / typical English sports / traditional Scottish skirt / painting / punting / sailing` (niezgodne), `modern Scottish dances / traditional and modern Scottish dances / professional Scottish dances` (uzupełnione niezgodnym elementem), `traditional dancing / traditional dances / to dance / dancing / and relaxing` (nieprecyzyjne), `Scottish dansing / danses / Schotland / Scottisch` (zła ortografia).

### 3.3. — `which are next to each other`
**Klucz**: pokoje uczestników położone są obok siebie.
**Akceptowane**: `adjacent to each other`, `adjoining each other`, `located next to one another`, `(situated) next door to each other`, `next door to one another`, `next to each other`, `right next to each other`, `side by side / beside each other`. Z dopuszczalnym błędem: `next to eachother`, `placed next door to each other`, `next-door to each other`.
**Odrzucone**: `neighboring / adjacent / door by door if they / close rooms / the nearby rooms / neighbour's room / as neighbours` (niespójne), `in close proximity / close to/near each other / close by / in the same building / closest to each other` (nieprecyzyjne), `next door / next to / next door each other / door to door / next to their room / put next door` (niejasne), `together / which are double / opposite each other / next to your room / next to students' rooms` (niezgodne).

### 3.4. — `the reception desk / (the) reception`
**Klucz**: ulotka ze szczegółami dostępna jest na recepcji.
**Akceptowane**: `(a/the) receptionist / receptionists`, `(a) reception`, `reception's desk`, `a reception desk`, `front desk / registration desk`, `a leaflet / leaflets`, `leaflets at the reception desk`. Z dopuszczalnym błędem: `a leeflet`, `reception desks`.
**Odrzucone**: `the organizers / desk` (nieprecyzyjne), `programme/camp coordinator / your tutors / the canteen / your rooms / the second floor` (niezgodne), `the reseption / the recepcion` (zła ortografia — wyraz wysokiej frekwencji).

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `corporation` zamiast `cooperation`</div>

Klucz CKE wprost klasyfikuje jako 0 pkt z błędem zmieniającym znaczenie: `corporation` (= korporacja, duża firma) zamiast `cooperation` (= współpraca). Jedna litera różnicy, kompletnie inne znaczenie.
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `tim work` zamiast `teamwork`</div>

`teamwork` jest jednym wyrazem (lub `team work` rozdzielnie). `tim work` = błąd ortograficzny zmieniający brzmienie — 0 pkt.
</div>
