## Jak liczyć przeniesienia ręcznie

Idziemy **od prawej**, sumujemy cyfry razem z przeniesieniem z poprzedniej pozycji:

```
  456789
+ 222222
--------
9+2 = 11  → przeniesienie (1), zapisujemy 1
8+2+1 = 11 → przeniesienie (2), zapisujemy 1
7+2+1 = 10 → przeniesienie (3), zapisujemy 0
6+2+1 = 9  → bez przeniesienia
5+2 = 7    → bez
4+2 = 6    → bez
```

Razem **3 przeniesienia**.

## Rozbicie punktacji 2.2 — cztery niezależne punkty

CKE punktuje algorytm składnikowo, więc warto zadbać o każdy element osobno:

1. **pętla po liczbie cyfr** `a` (i `b`) — `dopóki a > 0`
2. **pobieranie cyfr** — `a mod 10`, `b mod 10`
3. **liczenie sumy z przeniesieniem** i wyznaczenie nowego przeniesienia
4. **poprawny wynik**, w tym inicjalizacja `wpamieci ← 0` i `p ← 0`

Nawet niedokończony algorytm może zebrać 2–3 punkty, jeśli te części są poprawne — dlatego opłaca się pisać go czytelnie i po kolei.

## To samo w Pythonie

```python
def przeniesienia(a, b):
    wpamieci = 0
    p = 0
    while a > 0:
        suma = a % 10 + b % 10 + wpamieci
        if suma >= 10:
            wpamieci = 1
            p += 1
        else:
            wpamieci = 0
        a //= 10
        b //= 10
    return p
```

Zgodne z ograniczeniami: żadnych tablic, żadnej konwersji na tekst, tylko `%`, `//` i porównania.
