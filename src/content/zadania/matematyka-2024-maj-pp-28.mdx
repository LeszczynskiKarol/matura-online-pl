## Trik — średnia nie zmienia się przy proporcjonalnym powieleniu

Średnia arytmetyczna to **suma podzielona przez liczbę elementów**. Jeśli każdy element zostanie powtórzony tę samą liczbę razy, to:

- suma rośnie tę samą liczbę razy
- liczba elementów rośnie tę samą liczbę razy
- iloraz (czyli średnia) **się nie zmienia**

To intuicja. Sprawdzimy formalnie.

<div class="kroki-lista">

<div class="krok">

**Zapisz średnią z $a, b, c$.**

$$\frac{a + b + c}{3} = 9$$

Stąd:

$$a + b + c = 27$$

</div>

<div class="krok">

**Oblicz średnią z $a, a, b, b, c, c$.**

$$\frac{a + a + b + b + c + c}{6} = \frac{2(a + b + c)}{6} = \frac{a + b + c}{3}$$

Czyli ta sama formuła co przed chwilą! Wynik:

$$\frac{a + b + c}{3} = \frac{27}{3} = 9$$

</div>

</div>

<div class="odpowiedz">
  <div>
    <strong>Odpowiedź: A</strong> — średnia jest nadal równa $9$.
  </div>
</div>

<div class="pulapka">
  <div class="pulapka-label">Typowe błędy</div>

**Odpowiedź D ($18$)** — wybiera ten, kto myśli „dwa razy więcej liczb = dwa razy większa średnia". **Niepoprawne**. Suma rzeczywiście rośnie dwukrotnie, ale **mianownik (liczba elementów) też rośnie dwukrotnie** — efekty się znoszą.

**Odpowiedź C ($4{,}5$)** — odwrotny błąd: „dwa razy więcej liczb = dwa razy mniejsza średnia". Też nieprawda — tylko gdy dorzucalibyśmy **zera** lub liczby równe średniej, ale tu dodajemy **te same** liczby co już są.

**Odpowiedź B ($6$)** — strzał arytmetyczny, brak rzeczywistego rozwiązania.
</div>

## Klucz pamięciowy

Powielenie **każdego** elementu tą samą liczbą razy → średnia bez zmian.

Dodawanie/odejmowanie **stałej** do każdego elementu → średnia zmienia się o tę stałą.

Pomnożenie **każdego** elementu przez stałą → średnia mnoży się przez tę stałą.

Te trzy reguły pokrywają 80% pytań o średnią na maturze. Sprawdź zawsze, czy operacja jest **jednostajna na wszystkich elementach** — wtedy zachodzą.
