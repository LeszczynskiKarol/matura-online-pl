## Co zrobić?

<div class="kroki-lista">

<div class="krok">

**Zastosuj wzór $2\sin A \cos B = \sin(A+B) + \sin(A-B)$.** Tutaj $A = 4x$, $B = 6x$:

$$4\sin(4x)\cos(6x) = 2 \cdot [2 \sin(4x) \cos(6x)] = 2[\sin(10x) + \sin(-2x)]$$

$$= 2\sin(10x) - 2\sin(2x)$$

(bo $\sin(-2x) = -\sin(2x)$)

</div>

<div class="krok">

**Wstaw do równania:**

$$2\sin(10x) - 2\sin(2x) = 2\sin(10x) + 1$$

Skróć $2\sin(10x)$ po obu stronach:

$$-2\sin(2x) = 1$$

$$\sin(2x) = -\frac{1}{2}$$

</div>

<div class="krok">

**Rozwiąż $\sin u = -\frac{1}{2}$** (gdzie $u = 2x$). Rozwiązania:

$$u = -\frac{\pi}{6} + 2k\pi \quad \text{lub} \quad u = \pi + \frac{\pi}{6} + 2k\pi = \frac{7\pi}{6} + 2k\pi$$

</div>

<div class="krok">

**Podziel przez $2$:**

$$x = -\frac{\pi}{12} + k\pi \quad \text{lub} \quad x = \frac{7\pi}{12} + k\pi, \quad k \in \mathbb{Z}$$

</div>

</div>

## Po co to umieć

**Wzory iloczynowe** trygonometrii:
- $2\sin A \cos B = \sin(A+B) + \sin(A-B)$
- $2\cos A \cos B = \cos(A-B) + \cos(A+B)$
- $2\sin A \sin B = \cos(A-B) - \cos(A+B)$

Wszystkie z karty wzorów CKE. Kiedy zobaczysz **iloczyn $\sin \cos$ z różnymi kątami**, prawie zawsze pomaga przejść do **sumy** za pomocą tych wzorów.
