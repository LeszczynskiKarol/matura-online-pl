## Co zrobić?

Uprość $(2a-3)^2 - (2a+3)^2$.

<div class="kroki-lista">

<div class="krok">

**Zauważ, że to jest różnica kwadratów.** Wzór:

$$A^2 - B^2 = (A - B)(A + B)$$

Tutaj $A = 2a - 3$, $B = 2a + 3$.

</div>

<div class="krok">

**Oblicz $A - B$ i $A + B$.**

$$A - B = (2a-3) - (2a+3) = 2a - 3 - 2a - 3 = -6$$

$$A + B = (2a-3) + (2a+3) = 2a - 3 + 2a + 3 = 4a$$

</div>

<div class="krok">

**Pomnóż wyniki.**

$$(A-B)(A+B) = (-6) \cdot 4a = -24a$$

</div>

</div>

<div class="odpowiedz">
  <div>
    <strong>Odpowiedź: A</strong> — $-24a$
  </div>
</div>

<div class="pulapka">
  <div class="pulapka-label">Typowy błąd</div>
  **Wybór D ($16a^2 - 24a$)** — wynik niepełnego rozwinięcia. Pokazuje, że ktoś nie dokończył odejmowania. Sprawdź jeszcze raz: po obliczeniu $(2a-3)^2 = 4a^2 - 12a + 9$ i $(2a+3)^2 = 4a^2 + 12a + 9$ odejmujesz i $4a^2$ oraz $9$ się skracają — zostaje $-24a$.

  **Wybór C ($18$)** — błędne odejmowanie znaków. Pamiętaj: odejmując $(2a+3)^2$ odejmujesz **całe wyrażenie**, nie tylko sam $(2a+3)$.
</div>

## Po co to umieć

Wzór różnicy kwadratów $A^2 - B^2 = (A-B)(A+B)$ pozwala uniknąć rozwijania dwóch kwadratów osobno. Oszczędzasz czas i unikasz błędów rachunkowych. To jeden z najczęściej używanych wzorów na maturze.
