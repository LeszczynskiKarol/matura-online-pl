## Klucz odpowiedzi (z wariantami CKE)

<div class="odpowiedz">
  <div>

### 9.1. — `finds it hard to get`
**Akceptowane**: `finds it harder/hardest to get`, `finds it hard getting`.
**Odrzucone**: `found it hard to get` (zły czas), `finds it hardly to get` (zły wyraz — `hardly` ≠ `hard`), `finds it something hard to get` (zła konstrukcja), `found out getting hard`, `finds that hard to get`, `finds himself hard in getting`, `finds hard time to get`.

### 9.2. — `was held (much/a bit/a little) later`
**Akceptowane**: `was being held later`, `had been held later`, `was to be held later`.
**Odrzucone**: `has been held later`, `was held lately` (zły wyraz — `lately` = ostatnio), `which was held later`, `had been held out later`, `was held up later` (zły phrasal verb), `was held on later`, `was held till later`, `was held to start later`, `was held more late`.

### 9.3. — `should have mentioned`
**Akceptowane**: `should've mentioned`, `should have made mention of`, `should have been mentioning`.
**Odrzucone**: `should've made no mention of` (przeciwny sens), `shouldn't have mentioned` (zaprzeczenie), `should have mentioned about` (zbędny `about` — `mention` jest tranzytywne).

### 9.4. — `had any doubt(s)`
**Akceptowane**: `had the slightest doubt`, `had doubts`, `had a doubt`, `did have any doubts`, `had had any doubt(s)`, `was having any doubts`, `had some doubt(s)`, `had been in doubt`, `did have a doubt`, `were to have any doubts`, `had that doubt`, `had been doubtful`, `happened to have a doubt`, `had been having doubts`, `had a single doubt`.
**Odrzucone**: `had doubt` (brak rodzajnika), `had got any doubt`, `had to doubt` (zła forma), `had doubted`, `will ever have doubts` (zły czas), `would have doubts`, `had a little doubt` (zły kwantyfikator), `had the doubt`, `have had any doubt` (zły czas), `had no doubt` (przeciwny sens!), `had my doubt`, `could have a doubt`, `was having doubt`, `had doubtness` (zła forma).

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `hard` vs `hardly`</div>

`hard` = trudny, ciężki. `hardly` = ledwo (≠ trudno). Klucz CKE: `finds it hardly to get` = 0 pkt z zła formą wyrazu.
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `mention about` (zbędny przyimek)</div>

`mention` jest **tranzytywne** — łączy się BEZ przyimka: `mention something` (NIE `mention about something`). Klucz CKE: `should have mentioned about` = 0 pkt.
</div>

<div class="pulapka">
  <div class="pulapka-label">Pułapka — `had no doubt` (przeciwny sens)</div>

Jeśli pierwsze zdanie sugeruje wątpliwość → drugie też musi sugerować. `had no doubt` = nie miał wątpliwości = przeciwny sens. Klucz: 0 pkt.
</div>

### Dla zdających z dysleksją

Akceptowane: `9.1. fidns it hard to get / finds it hard geting`, `9.2. was held leter / wos held later`, `9.3. should have metioned / should hav mentioned`, `9.4. had any doutb / had douts`.
