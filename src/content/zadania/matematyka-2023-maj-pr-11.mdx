## Co zrobić?

Trzy warunki: (1) $m \neq 2$ (dziedzina), (2) $\Delta > 0$ (dwa różne rozwiązania), (3) $x_1^3 + x_2^3 > -28$.

<div class="kroki-lista">

<div class="krok">

**Wzory Viety.** Dla $x^2 + 4x + c = 0$ z $c = -\frac{m-3}{m-2}$:

$$x_1 + x_2 = -4, \quad x_1 x_2 = -\frac{m-3}{m-2}$$

</div>

<div class="krok">

**Warunek $\Delta > 0$:**

$$\Delta = 16 - 4 \cdot \left(-\frac{m-3}{m-2}\right) = 16 + \frac{4(m-3)}{m-2}$$

$$= \frac{16(m-2) + 4(m-3)}{m-2} = \frac{20m - 44}{m-2} = \frac{4(5m-11)}{m-2}$$

$\Delta > 0 \iff \frac{5m-11}{m-2} > 0 \iff m < 2$ lub $m > \frac{11}{5}$.

</div>

<div class="krok">

**Wyraź $x_1^3 + x_2^3$ przez Viete'a:**

$$x_1^3 + x_2^3 = (x_1 + x_2)\left[(x_1+x_2)^2 - 3 x_1 x_2\right]$$

$$= -4 \cdot [16 - 3 \cdot x_1 x_2] = -64 + 12 x_1 x_2$$

Warunek: $-64 + 12 x_1 x_2 > -28 \iff x_1 x_2 > 3$.

</div>

<div class="krok">

**Rozwiąż $-\frac{m-3}{m-2} > 3$:**

$$\frac{m-3}{m-2} < -3 \iff \frac{m-3 + 3(m-2)}{m-2} < 0 \iff \frac{4m-9}{m-2} < 0$$

Zerówki: $m = \frac{9}{4}$ i $m = 2$. Iloraz $< 0$ ⟺ $2 < m < \frac{9}{4}$.

</div>

<div class="krok">

**Część wspólna obu warunków:**

- $\Delta > 0$: $m < 2$ lub $m > \frac{11}{5}$
- $x_1^3 + x_2^3 > -28$: $2 < m < \frac{9}{4}$

Przecięcie: $\frac{11}{5} < m < \frac{9}{4}$.

</div>

</div>

<div class="odpowiedz">
  <div>
    $m \in \left(\dfrac{11}{5},\ \dfrac{9}{4}\right)$
  </div>
</div>

<div class="pulapka">
  <div class="pulapka-label">Typowy błąd</div>
  **Pominięcie warunku $\Delta > 0$.** Sam warunek na $x_1^3 + x_2^3$ daje $2 < m < \frac{9}{4} = 2{,}25$. Ale dla $m$ między $2$ a $\frac{11}{5} = 2{,}2$ równanie ma rozwiązania zespolone — wzory Viety wciąż działają (formalnie), ale rozwiązania nie są rzeczywiste.

  **$\frac{11}{5}$ vs $\frac{9}{4}$ — kolejność.** $\frac{11}{5} = 2{,}2$, $\frac{9}{4} = 2{,}25$. Przedział jest „cienki" — $0{,}05$ szerokości. Łatwo o pomyłkę.

  **Wzór $x_1^3 + x_2^3$.** $(a+b)^3 = a^3 + b^3 + 3ab(a+b)$, więc $a^3 + b^3 = (a+b)^3 - 3ab(a+b) = (a+b)[(a+b)^2 - 3ab]$.
</div>

## Po co to umieć

**Wzory Viete'a** dla $ax^2 + bx + c = 0$ z rozwiązaniami $x_1, x_2$:
- $x_1 + x_2 = -\frac{b}{a}$
- $x_1 x_2 = \frac{c}{a}$

Pozwalają wyrazić **dowolne symetryczne wyrażenie** $x_1, x_2$ przez współczynniki, bez liczenia samych pierwiastków. Klasyk PR.

Wyrażenia symetryczne:
- $x_1^2 + x_2^2 = (x_1+x_2)^2 - 2 x_1 x_2$
- $x_1^3 + x_2^3 = (x_1+x_2)^3 - 3 x_1 x_2(x_1+x_2) = (x_1+x_2)[(x_1+x_2)^2 - 3 x_1 x_2]$
- $\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1 x_2}$
