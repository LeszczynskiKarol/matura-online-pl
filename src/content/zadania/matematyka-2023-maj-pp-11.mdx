## Co zrobić?

Trzeba zidentyfikować **dwa układy** spośród A–F, które poprawnie opisują dane.

<div class="kroki-lista">

<div class="krok">

**Zapisz fakty:**
- Obwód prostokąta: $2a + 2b = 30$, równoważnie $2(a + b) = 30$, czyli $a + b = 15$.
- $a > b$ i jeden bok jest o $5$ krótszy: $a - b = 5$, równoważnie $b = a - 5$.

</div>

<div class="krok">

**Sprawdź każdą odpowiedź:**

| Odp. | Obwód | Różnica | Status |
|---|---|---|---|
| A | $2ab = 30$ (to pole!) | $a - b = 5$ ✓ | ❌ błędny obwód |
| B | $2a + b = 30$ (jeden bok dwa razy) | $a = 5b$ ❌ | ❌ |
| C | $2(a+b) = 30$ ✓ | $b = a - 5$ ✓ | ✅ |
| D | $2a + 2b = 30$ ✓ | $b = 5a$ ❌ (sprzeczne z $a > b$) | ❌ |
| E | $2a + 2b = 30$ ✓ | $a - b = 5$ ✓ | ✅ |
| F | $a + b = 30$ ❌ (powinno być $15$) | $a = b + 5$ ✓ | ❌ |

</div>

<div class="krok">

**Wybierz: C i E.**

</div>

</div>

  <div>
    <strong>Odpowiedź: C, E</strong>
  </div>

<div class="pulapka">
  <div class="pulapka-label">Typowy błąd</div>
  **Wybór F** zamiast E — pomylenie obwodu prostokąta z połową obwodu. Prostokąt ma 4 boki, więc obwód to $2a + 2b$, nie $a + b$.

  **Wybór A** zamiast C — pomylenie pola ($ab$) z obwodem ($2a + 2b$). Pole jest dwuwymiarowe, obwód jednowymiarowy.

  **Wybór B/D** — pomylenie różnicy z proporcją. „Krótszy o $5$" znaczy $b = a - 5$ (różnica), nie $a = 5b$ czy $b = 5a$ (proporcja).
</div>

## Po co to umieć

Modelowanie tekstu w język matematyczny — najtrudniejsza umiejętność na maturze podstawowej. Klucz: zapisz **każdy fakt z treści** jako równanie, potem dopiero szukaj odpowiedzi w opcjach. Tu są **dwa fakty** (obwód, różnica boków) → **dwa równania w układzie**.
