## Model danych

```
klienci (IdKlienta, Imie, Nazwisko, Plec)
    │ 1
    │
    │ n
transakcje (IdTransakcji, DataTransakcji, IdKlienta, IdSklepu, IdSprzedawcy)
    │ 1
    │
    │ n
opis_transakcji (IdTransakcji, IdProduktu, Cena, Liczba)
```

Wartość transakcji to `SUM(Cena * Liczba)` po wierszach z `opis_transakcji`.

## Zapytania do podpunktów 8.1–8.4

```sql
-- 8.1 klient z największą liczbą transakcji
SELECT k.Imie, k.Nazwisko, COUNT(*) AS ile
FROM transakcje t JOIN klienci k ON k.IdKlienta = t.IdKlienta
GROUP BY k.IdKlienta ORDER BY ile DESC LIMIT 1;

-- 8.2 klienci bez żadnej transakcji, wg płci
SELECT Plec, COUNT(*)
FROM klienci
WHERE IdKlienta NOT IN (SELECT IdKlienta FROM transakcje)
GROUP BY Plec;

-- 8.3 kasy samoobsługowe: liczba sklepów i łączna kwota
SELECT COUNT(DISTINCT t.IdSklepu), SUM(o.Cena * o.Liczba)
FROM transakcje t JOIN opis_transakcji o ON o.IdTransakcji = t.IdTransakcji
WHERE t.IdSprzedawcy IS NULL;

-- 8.4 sprzedawca w największej liczbie różnych sklepów w jednym miesiącu
SELECT IdSprzedawcy, MONTH(DataTransakcji) AS m,
       COUNT(DISTINCT IdSklepu) AS sklepy
FROM transakcje
WHERE IdSprzedawcy IS NOT NULL
GROUP BY IdSprzedawcy, m
ORDER BY sklepy DESC LIMIT 1;
```

## Trzy konstrukcje SQL, które to zadanie sprawdza

| Konstrukcja | Po co tutaj |
|---|---|
| `COUNT(DISTINCT …)` | liczenie **różnych** sklepów, nie transakcji (8.3, 8.4) |
| `NOT IN` / `LEFT JOIN … IS NULL` | klienci **bez** transakcji (8.2) |
| `LIKE '%fragment%'` | dopasowanie **fragmentu** tekstu (8.5) |
